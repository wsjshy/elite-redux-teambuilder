# 配队联动口径（v4.346–v4.369 沉淀）

> 适用于 `index.html` 里所有「特性 × 招式 × 道具 × 流派」的联动判定。
> 这不是机制手册，是**判定纪律**：什么样的联动可以推、什么时候不能推。

## 一、总原则：代价 → 解法池 → 条件匹配

任何「有代价的强化/机制」都不能绑死一个解，按三段走：

1. **代价**：先说清这个机制让哪一项变差（破壳 -2 防 / -2 特防；杂技要求道具位已消耗；生命宝珠每回合自伤；讲究件锁招）。
2. **解法池**：把所有能抵消代价的手段列出来（道具 / 招式 / 特性 / 速度线 / 队伍轮转），至少 3 条。
3. **条件匹配**：只在这些条件成立时把某个解提首位；否则降为「备选」或干脆不提。

强绑定（`只要 X 就带 Y`）一律不允许。至少要多条件同时成立才绑，并且默认给次优解。

## 三、已勘察但无需改（书面收口）

- **达人带（293）**：用 `defMult` 逐属性核验 44 条首推流派的伤害招克制面，结果 0 条不达标（克制属性数 3–4 的 3 条、≥5 的 41 条），且流派名全部是进攻型（胆量无盲流 / 雨强化清场 / 水泡水系炮台 / 场地增伤清场 / 雪强化清场）。达人带无自伤、克制时 +20%，与这些流派的打法一致，不做替换。
- **讲究件整体分布**：全库仅头带 3、眼镜 0、围巾 4 条进入候选，首位均为宝珠；引擎没有硬用锁招道具，唯一该推的场景（一猩一意）已在 v4.354 落地。
- **发电机（id477，源码 abilities.cc 6281 / battle_util.c 7174）**：入场未蓄电时，电场已激活则直接蓄、否则每入场只蓄一次；CHARGED_UP 且电属性招 modifier ×2.0，命中后消耗（非 MULTIPLETURNS、目标无 Energized），下场清空。v4.365 已落规则：四招无电属性伤害招＝死。
- **不仁不义**：自身能挂毒/麻痹/减速（特性级如静电/毒刺/孢子优先，否则招式池）即活；自身无手段再看整队，整队零挂状态手段才判死。v4.365 已落此队伍级规则。
- **天气依赖类（沙隐/沙之力＝沙暴，白茫茫/冰冻之躯/拨雪/暴雪之力＝冰雹）**：自身或队伍有天气特性（扬沙/降雪）或天气招（沙暴201/冰雹258）即活，整队零天气源才判死。ER 只有 HAIL 无 Gen9 雪。v4.365 已落规则。
- **天气/场地触发类（叶绿素/太阳之力/叶绿体/悠游自如/雨盘/速度之力/草之皮毛）**：自身或队伍有对应天气/场地源即活，整队零源才判死。v4.366 已落规则。干燥皮肤另带水吸收免疫（独立收益），不判死。
- **受击触发四特性（空气动力学 / 好烤的身体 / 登山者 / 危险预知）**：触发源在对手侧，己方数据不可证伪，只做覆盖率软提示，不判死。

## 七、进攻流派同玩法去重（v4.371）

- 背景：同物种多个进攻流派若特性/道具/EV/招组近同，属于同一玩法的重复平铺，应收敛为唯一最优解。
- 「同玩法」判据（同时成立）：同 side + 同主推特性名 + 同主推道具名 + 同 EV 模板，且主招 id 集合 Jaccard ≥0.6（4 槽至少 3 槽重合；同招仅排序不同 = 1.0）。
- 处理：并查集聚类，每簇保留评分最高一条，并列保留先出现冠名。防御/辅助流派（肉盾/受队/联防/辅助或 side=辅助）不参与；score99 同配置近同卡同样合并。
- 边界：同招但特性或道具不同（如讲究头带 vs 生命宝珠）不算同玩法，保留；招组重合 ≤2 槽（Jaccard≤0.33）不算同玩法。
- 全库：94 物种去掉 96 流派，4465→4369，无空流派，其余指标不变。

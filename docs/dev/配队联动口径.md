# 配队联动口径（v4.346–v4.362 沉淀）

> 适用于 `index.html` 里所有「特性 × 招式 × 道具 × 流派」的联动判定。
> 这不是机制手册，是**判定纪律**：什么样的联动可以推、什么时候不能推。

## 一、总原则：代价 → 解法池 → 条件匹配

任何「有代价的强化/机制」都不能绑死一个解，按三段走：

1. **代价**：先说清这个机制让哪一项变差（破壳 -2 防 / -2 特防；杂技要求道具位已消耗；生命宝珠每回合自伤；讲究件锁招）。
2. **解法池**：把所有能抵消代价的手段列出来（道具 / 招式 / 特性 / 速度线 / 队伍轮转），至少 3 条。
3. **条件匹配**：只在这些条件成立时把某个解提首位；否则降为「备选」或干脆不提。

强绑定（`只要 X 就带 Y`）一律不允许。至少要多条件同时成立才绑，并且默认给次优解。

## 三、已勘察但无需改（书面收口）

- **达人带（293）**：用 `defMult` 逐属性核验 44 条首推流派的伤害招克制面，结果 0 条不达标（克制属性数 3–4 的 3 条、≥5 的 41 条），且流派名全部是进攻型（胆量无盲流 / 雨强化清场 / 水泡水系炮台 / 场地增伤清场 / 雪强化清场）。达人带无自伤、克制时 +20%，与这些流派的打法一致，不做替换。
- **讲究件整体分布**：全库仅头带 3、眼镜 0、围巾 4 条进入候选，首位均为宝珠；引擎没有硬用锁招道具，唯一该推的场景（一猩一意）已在 v4.354 落地。
- **发电机（ER 自定义「入场或电气场地蓄电」）**：兑现代价（次数、是否叠加、离场是否保留、无电招时有无独立收益）无法从公开资料确证，v4.362 探针命中的 6 条（电飞鼠 3、水晶灯火灵R 3）**不落死规则**，留作待引擎核实。
- **不仁不义（Merciless 扩展）**：判死需要「整队零挂状态手段」的队伍级视角（队友能挂毒/麻痹/流血/减速即活），单 build 视角不可证伪，本批不判死。
- **天气依赖类（沙隐 / 沙之力 / 白茫茫 / 冰冻之躯）**：同样要整队零天气源才算死；且「白茫茫」映射对象（雪隐 or 冰冻之躯）未核实，不落规则。
- **受击触发四特性（空气动力学 / 好烤的身体 / 登山者 / 危险预知）**：触发源在对手侧，己方数据不可证伪，只做覆盖率软提示，不判死。
- **狙击手 / 超幸运**：基础暴击 1/24 保底，几乎恒为非零软收益，除非全队无可暴击招（纯变化招），不做死判定。
- **神枪手 / 炮术**：官方无对应机制，依赖 flag（bullet/slicing/自定义）与倍率均未核实，不落规则。

## 四、写 why 的要求

- 一句话说清「为什么是它」，不写机制百科。
- 带代价的推荐必须同时给代价与解法，例：「破壳后仍可能被超速打回：香草抹平 2 级防 / 特防，先把破绽补上」。
- 备选与首推的文案要能区分开，用户一眼能看出「这是唯一解」还是「这是三选一里的首选」。

# 配队联动口径（v4.346–v4.351 沉淀）

> 适用于 `index.html` 里所有「特性 × 招式 × 道具 × 流派」的联动判定。
> 这不是机制手册，是**判定纪律**：什么样的联动可以推、什么时候不能推。

## 一、总原则：代价 → 解法池 → 条件匹配

任何「有代价的强化/机制」都不能绑死一个解，按三段走：

1. **代价**：先说清这个机制让哪一项变差（破壳 -2 防 / -2 特防；杂技要求道具位已消耗；生命宝珠每回合自伤；讲究件锁招）。
2. **解法池**：把所有能抵消代价的手段列出来（道具 / 招式 / 特性 / 速度线 / 队伍轮转），至少 3 条。
3. **条件匹配**：只在这些条件成立时把某个解提首位；否则降为「备选」或干脆不提。

强绑定（`只要 X 就带 Y`）一律不允许。至少要多条件同时成立才绑，并且默认给次优解。

## 二、四条已验证的落地

| 机制 | 代价 | 解法池 | 判定 |
|---|---|---|---|
| 破壳（504） | -2 防 / -2 特防 | 香草抹平、替身/守住/睡觉挡回合、结实/多鳞硬吃、先手清场、队友接走降防回合 | 招里有破壳时：速度后 ≥110 且 ≥2 个本系威力≥80 招 → 首推进攻件、香草只备选；有替身/守住/睡觉或结实/多鳞 → 不提香草；都缺 → 才香草首位 |
| 杂技（512）/ 轻装 | 要求「身上没有道具」 | 一次性消耗品（宝石 / 果 / 香草 / 气球 / 披带 / 弱点保险 / 属性减伤果） | 只留 `CONS_ITEM` 白名单，常驻件（剩饭/厚底靴/讲究件）不能出现在杂技流派的道具位 |
| 收获 / 贪吃鬼 | 没有果 = 特性白拿 | 文柚果、属性减伤果、回收利用（重造果）、替身锁血配合 | 道具位空且非杂技 → 文柚果首位；专属件占位 / 杂技要宝石 / 剩饭厚底靴是续航骨架 → 特性降次推，不硬换 |
| 单纯 / 无防守 | 单纯没强化招、无防守没一击必杀 = 白拿 | 同侧强化池 `_SPEC`/`_PHYS`、`_OHKO` | 有就补进非核心伤害位；一个都学不会 → 降次推 |
| 生命宝珠 | 每回合自伤 10% | 常驻续航（剩饭 / 黑色污泥）、吸血招（终极吸取等比例回复吃 30% 加成） | 消耗/联防流派 + 固定回复招 → 换剩饭/黑色污泥；吸血类保持宝珠 |

## 三、写 why 的要求

- 一句话说清「为什么是它」，不写机制百科。
- 带代价的推荐必须同时给代价与解法，例：「破壳后仍可能被超速打回：香草抹平 2 级防 / 特防，先把破绽补上」。
- 备选与首推的文案要能区分开，用户一眼能看出「这是唯一解」还是「这是三选一里的首选」。

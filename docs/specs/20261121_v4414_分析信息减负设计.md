# v4.414 设计：队伍分析信息减负（三级信息层，默认只给结论）

日期：2026-11-21
触发：用户反馈「好多内容尤其分析还是太繁杂了，导致信息获取难度太高」。
范围：以「队伍分析」Tab（`#tab-analyze` / `#anOut`）为主，兼顾 `#tmAnalyze`（队伍构建页）的冗余与硬编码清理。
不做：不删任何判定能力与数据，只做「默认隐藏 / 折叠 / 合并 / 缩短」；不拆函数、不拆文件、不改引擎派生层。

## 1. 现状量化（六人队 [26,65,96,80,37,208]，1300px 宽，真实浏览器 CDP 实测）

- 整个分析 Tab：1741px 高、1706 字、36 个卡片容器。
- `#anOut` 默认展开 1126px，其中「配队体检卡」596px。
- 体检卡共 25 个可读条目：
  - 3 个速览行（胜负手 / 钉子 / 入场税），术语密集（入场税一行 12 个百分比）；
  - 硬伤 3 条（红）；
  - 提示 11 条（橙，默认露 2 条其余折叠）；
  - 参考 8 条（灰，整组折叠，含打穿速度/最坏情况/换哪招等小众数学）。
- 标题平铺 17 个检查分类；标题下另有约 150 字方法论说明。

## 2. 核心问题

1. 概念面过宽：17 个分类名 + 大量术语（入场税、角色压缩、破受），玩家要先学概念才能读。
2. 「没问题」也占篇幅：弱点分布过关、反强化有答案、状态有答案等正面确认，稀释真正的问题。
3. 重复：弱点在体检硬伤 / ②联防 / ⑤诊断三处同源重复；钉子在速览行 + 提示重复；先制弱点 3 只各一条近乎相同的文案；体系标签 + 细化体系两张卡语义重叠。
4. 小众数学参考（打穿速度、最坏情况、换哪招、招式价值）对普通玩家信息价值低。

## 3. 三级信息层（目标结构）

- 第一层（默认，首屏）：队伍槽位 + 体检短标题 + 硬伤（红色全给，可执行）+ 成员一览（图）。
- 第二层（一个折叠按钮）：提示 11 条（建议优化项）。
- 第三层（折叠/副弹窗）：速览三行 + 参考 8 条 + 方法论口径 + 画像细节/联防/完整配置/叙事/诊断/深度维度（沿用既有 6 个 anSecMark 折叠）。

## 4. 具体改动清单

A. 体检卡（`_teamCheckHtmlCore` / `_tcVList`）
- 长标题（17 分类）改为短标题「🩺 队伍体检」；保留「硬伤 N 条 · 提示 N 条」计数。
- 方法论长段落收进「判定口径」轻量折叠（details 风格，复用 tcMore 按钮模式，不新增空 catch）。
- 硬伤默认全量红色展示。
- 提示改为整组默认折叠（一个「提示 N 条（建议优化）」按钮），不再默认露 2 条。
- 速览三行（胜负手/钉子/入场税）移入第三层折叠区，不占默认首屏。
- 参考维持整组折叠（含小众数学）。

B. 合并重复（展示层）
- 先制弱点：同一批 setupMems 的多条先制提示合并为 1 条，按只列出（例：催眠貘/呆壳兽 弱突袭×2、影子偷袭×2；大钢蛇 弱音速拳×2、水流喷射×2、真空波×2）。
- 体系标签 + 细化体系合并为一张卡，两个标签共存时并排展示。
- 对手侧两条 wall 提示保持各自折叠入口但文案去重（去掉重复的「怎么修」长句前缀）。

C. 顶部与冗余清理
- `anRuleTip` 满队文案缩短为一句。
- 删除 `renderAnalyze` 内空循环（L6440-6441 `ac2=atkCovers(); ac2.per.forEach(function(row){})`），`ac2` 改为直接用既有 `ac`。
- 硬编码颜色变量化：`#7f1d1d` → 前景危险变量；`#c8e6c9`/`#eceff1`（L6479 打击面 chips）→ 现有绿/灰变量。

## 5. 验收口径（量化）

- 默认首屏可读条目：由 25 条降到「硬伤 3 条 + 成员一览」；`#anOut` 默认高度显著下降（目标 ≤ 700px）。
- 所有判定数字（V 的条数、严重度分布、补位候选）与改前一致，仅位置/折叠态变化。
- 门禁：check_inline_syntax 6 段通过；smoke 全过且体积/注释占比不超限；静默 catch 不增加（现 390 贴线）；verify_invariants 0 违规；CRLF/bare LF 与基线一致。
- 深色模式：折叠区与新短标题在 light/dark 下均无 r<1.5 硬伤。

## 6. 风险与回滚

- 风险：折叠结构改动可能让老玩家找不到原入口 → 所有原内容仍在，仅多一层折叠，折叠按钮文案带完整 hint。
- 回滚：`%TEMP%\\index_before_v4414.html` 为 v4.413 干净态，可整体还原。

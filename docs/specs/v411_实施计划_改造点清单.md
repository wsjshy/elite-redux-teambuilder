## 1. 用户拍板 6 项（已对齐，实施必须遵循）

| # | 事项 | 最终决策（锁定） | 与规格默认差异 |
|---|---|---|---|
| B1 | 努力值输出形态 | **6 位数组 + 文本摘要双字段**：`alloc` 六维数组（顺序 HP/物攻/物防/特攻/特防/速度）+ `summary` 文本（如 `252HP/252攻/4防`）；UI 同时呈现数组串（`0/252/4/0/0/252`）+ 摘要 + 252/252/4 条形图 | 输出字段按用户口径固化 |

| B3 | 空间模板速度 | **不强制速度 0，仅建议非强制**（ER 有服务铃等提速机制）；alloc 按建议给出 0，但 UI 附注「速度归零仅为建议，服务铃等机制可提速」 | 规格默认「强制 0」→ 用户改为非强制 |

| B5 | 「你拥有」标记 | **未导入存档时不显示**；导入后对存档池实际持有宝可梦投影「你拥有 ✓ / 未拥有」 | 与规格默认一致 |
| B6 | 词条解释呈现 | **>40 字用轻量弹层（小尺寸、可关闭、不遮挡）**；**≤40 字内联展开** | 阈值 40 字固化 |

## 2. 三层改造点清单（实施核对用）

### 2.0 全局（renderCore 及 CSS 层）

- [ ] 详情页重构为三层骨架：L1 基础信息层（恒定可见）→ L2 流派玩法层（tab/卡片切换，一次一卡）→ L3 引擎细节层（默认折叠「引擎视角 ▸」）。
- [ ] 所有展开为**就地展开（accordion，推挤下方内容）**，禁止全屏 modal 遮挡；唯一例外：L1 词条解释 >40 字的轻量弹层（§1 B6）。
- [ ] 点击区最短边 ≥ 44px（CSS px）；PC 鼠标态视觉可略小但热区保持 44px（padding / ::before 扩展）。
- [ ] `prefers-reduced-motion` 下关闭过渡与动画。
- [ ] 无障碍：折叠控件 `button` + `aria-expanded`；tab 用 `role=tablist` + 方向键；对比度 ≥ WCAG AA。
- [ ] 默认只显示一层：任何 L3 内容 / 溯源默认收起；切换 tab、重进详情页回到收起。
- [ ] 无数据不输出空壳（无天性不显示天性 chip 等）。
- [ ] 六维条形图始终可见（L1 基础，不折叠）。

- [ ] 流派 tab 切换（PC 横排 / 移动横滑 + sticky ≤48px），**一次一卡不堆叠**。
- [ ] 每卡固定 8 字段（顺序固定，缺失跳过不占位）+ 可选 ⑨ 注意点：

| 字段 | 要求 | 来源 |
|---|---|---|

## 3. 努力值分配推荐（v4.11 新增输出，§1 B1/B2/B3 落地）

- **输出结构**（建议）：`bd.ev = { template: '速攻'|'耐久'|'空间低速'|..., alloc: [hp, atk, def, spa, spd, spe], summary: '252HP/252攻/4防' }`
  - 6 位数组顺序：HP/物攻/物防/特攻/特防/速度；UI 呈现数组串 `0/252/4/0/0/252` + 摘要 `252HP/252攻/4防` + 条形图。
- **模板规则**：
  - 速攻：252 速度 / 252 主要输出（物理→物攻、特殊→特攻）/ 4 余量。
  - 耐久：252 HP / 252 主要防御（**物盾→物防、特盾→特防，按流派定位动态取**）/ 4 余量。
  - 空间低速：252 HP / 252 主要输出 / 4 余量；速度建议 0（**非强制**，UI 附注「服务铃等机制可提速」）。
- **模板选取**：`bd.side`（物理/特殊/受向/空间）+ `bd.roleTag` 驱动。
- **落点**：`build_tool_html.py` 流派卡渲染（L2 字段 ⑥）；数据在引擎内计算或 `build_tool_data.py` 追加，只追加字段不改动既有推荐结果。
- **摘要文本规则**：非零维按「数值+维名」列出（HP/攻/防/特攻/特防/速），用 `/` 连接，如 `252HP/252攻/4防`。

### 3. 「天使暴怒」实证结论（本轮核心）

数据层与 ROM 官方文本都只有一句：`Drastically alters all of the users moves.`
`include/constants/abilities.h` 里也只有一行注释。**真实机制在 `src/battle_util.c`**：

- **L8978** `if(BATTLER_HAS_ABILITY(battler, ABILITY_ANGELS_WRATH))` → `switch(move)`，**只覆盖 7 个招式**
- **L12816** 威力覆盖，**L15252** 属性相性覆盖

| 招式 | 实际效果 |
|---|---|
| 撞击 Tackle | 威力 40→100；命中且目标未挂再来一次/定身法时，给目标挂 encore 2 回合 + disable 2 回合（锁住目标的第一个招式） |
| 毒针 Poison Sting | 威力 15→120；打**钢属性**改为效果绝佳 ×2（正常毒打钢是 0 无效） |
| 电网 Electroweb | 威力 55→155；命中后目标速度等级清零 + 无法逃走/换人；打**地面属性**改为效果绝佳 ×2（正常电打地面是 0 无效） |
| 咬虫 Bug Bite | 威力 60→140；吃掉/销毁对手持有道具，并给自身回复 |
| 吐丝 String Shot | 一次给对手一侧布下隐形岩 + 毒菱 + 撒菱 + 黏黏网四种钉子（对方已有任一钉则不触发） |
| 变硬 Harden | `for(i=1;i<NUM_STATS;i++)` 除防御外**全部能力等级 +1** |
| 铁壁 Iron Defense | 置 `angelsWrathProtected`，在 L12298 被消费：挡下对方**威力≠0 的攻击招式**，变化招式不挡 |

**「彻底更改所有招式」是失实描述**：其余招式完全不变。这一条已写进 `ABI_DETAIL['439'].head`。

### 4. 「拳舞 #733」实证结论（第二批）

数据层只有一句「所有招式都算作舞类招式」，看不出打这个标记有什么用。
证据链在源码里闭合：

- **L9661-9675**：`CHECK_ABILITY(ABILITY_TWO_STEP)` + `gBattleMoves[move].flags & FLAG_DANCE`
  → `UseAttackerFollowUpMove(..., MOVE_REVELATION_DANCE, 50)`，即**追加一发固定威力 50 的觉醒之舞**
- **L9222-9229**：`ABILITY_DANCER` 同样只看 `FLAG_DANCE`，别人放舞类招式时跟着复刻

而数据层 **`#517 跟舞`** 的描述正是「使用舞类招式后触发 50 威力的觉醒之舞」——两边完全对上。

**结论**：拳舞不改任何招式，只把「舞类」标记打到全部招式上；有跟舞时**每一招都会追加一发 50 威力觉醒之舞**，
没有跟舞/舞者时它几乎不产生实际收益。已写进 `ABI_DETAIL['733']`。

`#788 冰川暴怒`「触发一格 50 威力的暴风雪」不需要手写详解 —— 它属于「触发某招式」句式，
自动展开已经能把暴风雪的效果原文附上。

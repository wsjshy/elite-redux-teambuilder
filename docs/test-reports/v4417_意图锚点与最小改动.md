# v4.417 测试报告 · 意图锚点 + 缺陷重分级 + 最小改动（2026-11-21）

## 1. 测试目标

验证针对用户「体检趋同化 / 最小改动」质疑的三批改造是否成立，且不破坏既有判定与门禁：

1. 队伍意图能否被正确识别（主题/姿态/核心/补位）。
2. 缺陷是否按「真硬伤 A / 可接受代价 B / 他法可解 C」相对意图重分级。
3. 换人是否遵守最小改动：核心锁定、对立天气阻断、无安全对象时禁用。
4. 全量门禁与不变量零回归。

## 2. 测试方法

- 纯浏览器黑盒（headless CDP，file:// 直开，轮询 `ERDATA` 就绪），不使用任何 Debug 跳过。
- 函数级探针逐值断言 + 真实卡片渲染截图 + 无头门禁三件套。

## 1. 起点：继续自主迭代时发现的自相矛盾

v4.433 发布闭环后，复查 INV06 剩余 7 红（日光束 76 / 日光刃 632 无晴源）的槽位说明时，发现一类**机制陈述与最终卡面配置直接冲突**的文案：

- **#986 猛恶菇[2]**（empty，破盾/消耗向）：日光刃 632 槽同时挂着
  - 「晴源/叶绿体：日光系免蓄力」
  - 「条件威力(已满足)」

  但这张卡最终特性是**适应力（91）**（备选真菌感染 398 / 菌丝之力 510），四招为 `818 / 632 / 74 生长 / 73 寄生种子`，**没有大晴天 241**，道具也不是力量香草。
- **#1817 裙儿小姐-洗翠[1]**（empty）/ [2]（six）：最终特性是**叶绿素 34**（只提速，**不**免日光蓄力），四招 `894 / 632 / 74 / 136`，同样无 241。
- **#1544 超级暴雪王[2]**（empty）/ [0]（six）：物种特性池里**有叶绿体 268**，但本张实际选中的是**北风**（走雪/冰雹体系，同句说明里就有「冰天雪地输出×1.2(冰雹)」、推荐特性「极北之风」开墙），四招 `419 / 76 / 14 / 191`，无 241、无香草。

也就是说，卡面一边在冰雹体系里给日光束加成，一边声称「晴天免蓄力已满足」，玩家照抄后实战仍要白等一回合。

## 2. 根因：两层「天气源」口径不同源（gates 第四十一节早已预警）

- 评分函数 `costOf(s,m,hasRec)` 是 **s 级（物种潜力）**，拿不到最终 build `b` 与队友 `team`：
  - `wxConditionMet(s) = ownWxList(s, learnOf(s)).length > 0`（约 L1856）——只要该物种**技能池能学到任意天气招**即为真，**不区分是不是晴天，也不要求最终四招真的带 241**。#986、#1817 正是因为能学 241 而判真。
  - 免蓄力特性判定 `_ttSunOk` 扫的是 `s.abis.concat(s.inns)` **整个可选特性池**里是否出现「叶绿体 / 耀斑 / 巨大树叶」（268/366/374），**不要求本张卡实际选中**。#1544 因此被判「有叶绿体」。
  - 命中后给招式打标签 `晴源/叶绿体：日光系免蓄力`（L1916）；weather-based 描述块又用同一个 `wxConditionMet` 打 `条件威力(已满足)`（L1923）。
- 成卡事实函数 `solarSelfSufficient(b)`（L1878）是 **b 级（当前配置）**：只认 `b.abi` 里**实际选中**的特性 id（70 日照 / 584 绯红脉动 / 190 / 871 / 268 叶绿体 / 366 耀斑 / 374 巨大树叶），或最终四招 `b.mv.main` 含 241。`herbCovers(b)` 只看主道具位 `b.it[0]` 是否力量香草。

**结论**：评分层回答的是「这个物种**能不能凑出**晴天/叶绿体」（用于潜力估价），展示层却把它写成了「**当前这张卡已经满足**」。两层都是有意设计（gates 第四十一节明确警告「costOf 是 s 级拿不到 b/team，别强行合并成一处」），所以本版**不动评分 mul**，只在成卡末尾做事实校正。

## 3. 方案选择（三选一，取最小风险）

1. **末尾展示层事实校正（采用）**：`_deriveBuildsCore` 在 `return out` 前自包 forEach，仅改写最终 76/632 槽的 why 文案。不动 `costOf`、不动选招、不动数值、不动道具。
2. 改 `_ttSunOk` / `wxConditionMet` 让天气类型与「已携带」更准：会改变评分倍率，进而改变全库选招，必须双快照逐卡解释；且 s 级阶段本来就无法知道最终选择，强行改会破坏潜力估价。**否决**。
3. 仅给 verify 加精确白名单（test-only）：能让 INV06 数字好看，但**玩家看到的错误文案仍在**，不治本。**不采用为主体**（INV06 七红的逐张定性维持 v4.431 结论）。

## 8. 边界、未做事项与复盘

- **未改评分潜力口径**：`costOf` 的 `wxConditionMet` / 全特性池扫描服务于「这个物种能做什么」的潜力估价，本身不是 bug；错的是展示层把潜力写成完成时。两层保持分离（gates 第四十一节）。
- **未重写第一类张冠李戴文案**：#5/#275/#615/#1814/#2225 的日光槽挂的是 v4.429 守住收口的通用替换说明（「本卡无两回合/反伤/剧毒寄生协同……→替换」），它记录的是「为什么换掉守住」，并非对日光束机制的错误断言；该叙事覆盖全库 333+ 个替换槽，若要改成逐招解释应作为独立主题，不在本版扩大。
- **叶绿素 34 ≠ 叶绿体 268**：#1817 选的叶绿素只提速，免蓄力特性仍是 268/366/374，未混淆。
- **复盘**：当一个评分标签来自物种级潜力、却渲染在具体成卡上时，最稳妥的收口位置是**成卡末尾的事实复核**（与替身 `substituteJustified`、守住 `protectJustified`、香草 `herbCovers` 同一模式），而不是回头让评分函数掌握它尚不知道的最终选择。判定与展示可以分层，但**展示给玩家的那句话必须能通过当前卡面配置的核验**。

## 二、补丁（17 处）

1. 主块顶部（最早的分页器声明之前）新增：
   ```js
   var LIST_STEP=60;
   function pagerDoneText(total,unit){return '共 '+total+' '+unit+' · 已全部显示'}
   ```
2. 六个步长全部改引用 `LIST_STEP`；特性区 `slice(0,60)`、`shown+60`、`Math.min(60,…)`、`_abiFill(60)` 等硬编码一并替换。
3. 5 处尾注字面改调 `pagerDoneText`（unit 取「只」或「个匹配」）。
4. 图鉴首批由 120 变为 60——唯一的用户可感知行为变化；触底自动加载本就存在，滚动后立刻补到 120，移动端首批更轻。

## 五、为什么不合并 DOM 分页器

四份分页实现的滚动容器不同（主容器 main、列内网格、整页卡片流），强行抽共用 DOM 渲染器需要传入大量回调并让模块互相耦合，违背最小改动原则；本次只统一「常量 + 文案」这两个真正的口径分裂点，DOM 结构维持原样。

## 五、踩坑记录（可复用）

1. **`esc(tlabel(...))` 二次转义**：`tlabel(ty)` 返回的是 HTML 片段（`<span class="t-t 超能力">超能力</span>`），再套 `esc` 会把整段变成可见文本，并因文本过长把弹窗撑高、底部按钮被挤出 70vh 可视区。修法是直接 `tlabel(x.ty)` 拼接。
2. **cu 截图显示尺寸 ≠ 真实屏幕**：截图为 1920×1080，若按显示尺寸（1067×600）折算坐标，点击会整体落到窗口外；`y` 差 12px 即命中容器 `.ansmate` 而不是词条 `.ansp`（`.ansp` 高度仅 25px）。准确定位做法：在页面里 `getBoundingClientRect()` 取元素中心，再用 `window.screenX` / `outerWidth-innerWidth` 反算窗口内容区原点。
3. **`javascript:` 注入可作旁证但不能替代手点**：注入 `mateQuickModal(Object.keys(window._MQ)[0])` 能验证弹窗渲染，但只有真实点击才能验证 `onclick` 属性拼接与命中区。两者都要过。
4. **alert 会吞掉后续 cu 输入**：注入诊断用的 `alert` 若未关闭，后续点击/键入都会被吞；必要时 `ctrl+r` 刷新清场。

## 一、指控的两条具体事实

1. **超级胡地 #1507**：`base [55,50,65,175,105,150]`、`bulk 225`、`spd 150`、`atkBest 175`、`isGlassCannon=true`，自己会 **347 冥想 + 417 阴谋**，`deriveBuilds` 也已给出「替身强化流[强化]」。它却被判为「双墙辅助手」——占两格开墙，等于把全队最好的矛拿去当盾。
2. **引梦貘人 #97**：`base [95,73,70,115,115,67]`、`bulk 280`、`spd 67`、`atkBest 115`、`isGlassCannon=false`，是典型「耐久慢速辅助」，却被选中当「强化推队手」。

即：**开墙的选了最该去推队的，推队的选了最推不动的**，且方向恰好互为镜像。

## 二、三条根因（均取证）

| # | 根因 | 证据 |
|---|---|---|
| ① | 双墙卡准入缺「辅助定位」门。钉子流早有 `&&!isGlassCannon`（玻璃大炮不做队伍级辅助），墙流反而在 v4.426 专为玻璃大炮新增「GC 高速开墙」分支（胆小 / 满速 EV / 特攻 252） | v4.426 墙块 `_wlGc=isGlassCannon(s)` 双配置；量化 GC 墙卡 70 物种 |
| ② | `mateRoleOf` 的「强化」角色只看 `_ER_BOOST_ROLE`，不看进攻力 → 慢速中火力照样占强化位 | 改前 #97 角色含「强化」、#1104 鼠霸王（113/54）在引梦貘人核心答案卡当强化手 |
| ③ | `_ER_BOOST_ROLE` 判据只有「主推流派 `mv.main` 含 剑舞/龙舞/诡计/蝶舞/破壳」，**漏了冥想 347** → 超级胡地根本不在表内 | 表内 `1507` 不存在（探针 `boostRole false`），而 `learnOf(#1507)` 同时含 347 与 417 |

根因③是本轮最隐蔽的一处：**表漏判让「最像强化手的那只」拿不到强化角色**，于是答案卡只能退而求其次挑一个"有强化招但推不动"的。

## 三、补丁（patch4427 a–d）

- **a｜强化推队手单一真源**：新增 `isBoostSweeper(t)` = 会强化（查 `_ER_BOOST_ROLE`）**且**进攻型（`atkBest≥95 && spd≥70`，与「输出」角色 `_off` 完全同源，不另立阈值）。`mateRoleOf` 的「强化」判定与 `NEED_KINDS.sweep` gate 两处替换为同一函数。
- **b｜墙卡准入排除玻璃大炮**：`comboBuildsOf` 墙块 `if(_wlVeil||_wlDual)` → `if(!isGlassCannon(s)&&(_wlVeil||_wlDual))`；整段删除 GC 高速开墙分支（性格/EV/模板/why 全部降为单一路径：防御性格 + HP252/物防252），并回退 v4.426 的 `_fastScreen` 哨兵及其四处放行（`sanitizeBuild` L13618、L16922、L18410、L18665）。
- **c｜强化角色表补冥想 347**：312 → 598 项（新增 286 个会冥想的物种，含 #1507）。
- **d｜强化槽内择优**：`_scan4426` 在 `want==='强化'` 时对候选追加 `min(12,(atkBest-95)/6) + min(6,(spd-70)/10)`，让强化位优先真正能推队的。

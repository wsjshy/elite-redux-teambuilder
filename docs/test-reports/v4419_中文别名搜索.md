# v4.419 测试报告 · 中文口语别名搜索（2026-11-21）

## 1. 目标

让俗称/口语名（如「鲤鱼龙」）能搜到官方物种（暴鲤龙），同时不引入模糊匹配噪声。

## 2. 取证

- 现有 `spMatch`→`fzAny` 仅做子串匹配，「鲤鱼龙」不是「暴鲤龙」子串，实测返回空。
- 通用 Levenshtein 兜底评估：「鲤鱼龙」到「暴鲤龙」距离为 2（超阈值），d=1 反而命中鲤鱼王、鳃鱼龙等噪声且打不到目标——通用模糊方案否决。

## 3. 改动

- 新增可扩展别名表 `SP_ZH_ALIAS={'鲤鱼龙':'暴鲤龙'}` 与 `spAliasNorm(q)`，按 token 映射俗称到官方名。
- 接入 spMatch 文本匹配，命中后按官方名走正常子串，返回全部形态。

## 4. 用例与结果

|---|---|---|---|
| 鲤鱼龙 | 暴鲤龙全形态 | 暴鲤龙/超级X/超级Y/R | PASS |

## 5. 门禁

- check_inline_syntax 6 段 PASS；harness 4,134,306 B；smoke 34/34（静默 catch 388、27 历史保留、DOM id 322）。
- gate 零漂移；verify_invariants 0 违规。
- index 2,121,662 → **2,121,937 B（净增 275）**，余量约 78KB。

## 6. 结论

确定性别名方案精准命中俗称、零噪声，常规搜索零回归；后续发现新口语名只需往别名表追加一行。

## 二、改法

**① `N-06` 句内**：当慢的那只就是队友自己（`spdOf(m)<=60`）时，第二个名字不再点名，改「自身」：

```js
var slow='';try{if(c&&spdOf(c)<=60)slow=c.zh;else if(m&&spdOf(m)<=60)slow='自身'}catch(e){}
```

结果：「队友 呆呆兽先开戏法空间（6 时段），**自身的**低速重炮先手且威力翻档」。
核心自己慢（`slow=c.zh`）时保持原样 —— 「超级喷火龙Y的低速重炮」，名字只出现一次，不算重复。

**② `mateWhyNarr` 跨句**：收集完成后统一后处理 —— 第二句起若以「队友 `mateS.zh`」开头、且前文已含该名、且前缀后面不是「（」，就把「队友 X」换成「它」：

```js
if(out.length>1){
  for(var q=1;q<out.length;q++){
    var _pn='队友 '+mateS.zh;
    if(out[q].indexOf(_pn)===0&&out[q].charAt(_pn.length)!=='（'&&out.slice(0,q).join('').indexOf(mateS.zh)>=0){
      out[q]='它'+out[q].slice(_pn.length);
    }
  }
}
```

**为什么排除「（」**：`N-04` 的文案是「队友 X（干旱）替你把晴铺开」。若前缀被换成「它」，会得到「它（干旱）替你…」—— 指代和括注粘在一起，读着别扭。带特性名的句子保留全名，指代反而更清楚。

**为什么可以放心用「它」**：条件是「前文已出现 `mateS.zh`」，指代对象唯一，不会和核心混淆（核心在文案里是「你」）。

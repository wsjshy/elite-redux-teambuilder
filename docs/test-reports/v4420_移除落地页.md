# v4.420 测试报告 · 移除核心配队落地页（2026-11-21）

## 1. 背景

用户反馈「这个入口根本一点用都没有」，经确认指核心配队首屏的「你想做什么？」三选一落地页。

## 2. 问题

- 落地页仅一次性（localStorage `er_landing_done`）把真正的核心搜索 `#corePickWrap` 隐藏，用户多点一步。
- 三张卡片只重复顶部导航：存档/随机等于跳 team 页执行操作，核心卡片只是露出搜索框。
- 属纯摩擦，违背「操作极简、默认单一最优解、减少选择成本」。

## 3. 改动（7 处，零功能删减）

1. 删除 `#erLanding` 整块 HTML。
2. 删除 `.lcard` / `.landing-cards` CSS（含深色覆盖）。
3. 删除 `erLandingGo` / `erLandingBack` 函数与落地 IIFE。
4. 删除核心搜索栏的「返回入口」按钮。
5. 空态存档/随机按钮改为直接调用（switchTab + 点击 savFile / randomTeamGen）。
6. 保留并简化 `#erGuideBar` 新手三步提示，移除对已删 landing 的引用，关闭逻辑仍走 `er_guide_v2`。

## 4. 用例与结果

| 用例 | 预期 | 结论 |
|---|---|---|
| 首次进入核心配队 | 直接显示搜索框 + 候选网格，无落地页 | PASS |
| 空态「载入存档」 | 跳 team 并打开文件选择 | PASS |
| 空态「随便先来一队」 | 跳 team 并生成随机队 | PASS |
| 新手提示条 | 首次显示，点 × 后不再出现 | PASS |
| 内联语法 | 6 段 ALL PASS | PASS |

## 5. 门禁

- harness 4,133,220 B；smoke 34/34（静默 catch 388、27 历史保留、DOM id 可解析）。
- gate 零漂移；verify_invariants 0 违规。
- index 2,121,937 → **2,119,293 B（净减 2,644）**，上限余量约 81KB。

## 6. 结论

去掉多余的一步选择，核心配队直达搜索，原有存档/随机/新手引导能力全部保留，无功能回归。

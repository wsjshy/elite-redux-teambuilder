## 六、排版五次迭代（内容要塞进已满的副弹窗）

| 版本 | 做法 | 结果 |
|---|---|---|
| a（首版） | 每属性一行 `火：2× 克制 …　0.5× 抵抗 …` | 「0.5× 抵抗」折行，不整齐 |
| b | 每属性两行（2× 一行 / 抵抗·无效 一行） | 整齐了，但整体要滚动 |
| c | `grid-template-columns:1fr 1fr` 两列 | 每列 250px 太窄，属性块折行更乱 |
| d | flex-wrap + 块状 chip | 彩色 `tlabel` 撑爆，chip 尺寸失控 |
| **e（定稿）** | **纯文本一行**（`esc(x.t)` + `esc(x.ok.join(' '))`，不嵌 `tlabel`），字号 13 / 行高 1.6 | 两行放下、无溢出、**滚动条消失** |

结论：`tlabel` 的彩色属性块不能密集并排 —— 每个块自带 padding 与最小宽度，在 <500px 容器里必然折行。纯文本反而能一行容下 4 个属性名。

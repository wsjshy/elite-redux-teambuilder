## 一、立项：五套手写判据互不同源

「两回合招」在引擎里被五处各自判断，措辞要求不一致：

| # | 位置 | 原判据 | 覆盖 |
|---|------|--------|------|
| 1 | `costOf`（≈L1870） | `on the first turn[^.]*(second\|next)` / `Fires on second turn` / `and then attacks on the next turn`，只扫 `m[10]` | 16 招 |
| 2 | `e5NonInstant`（≈L14720） | 同上 + `recharg` / `Can only be used every-?other turn` / `must rest` | 16 招 |
| 3 | `_CHARGE_R` 两处（L17448 与 L17527 内联名表） | 按中文名表（只写「日光束」，漏「日光刃」） | 名表 |
| 4 | verify 统计 `nE5` | 同 #1 | 16 招 |
| 5 | `_v9charge` / `_v10charge` / `_v11charge` | 按名，漏日光刃/流星光束 | 名表 |

**根因**：日光束 76 的 `m[9]` = `Absorbs light in one turn, then attacks next turn.`，日光刃 632 的 `m[9]` = `Charges first turn...`，都不含 `on the first turn`，而 #1 只扫 `m[10]` → 76/632 从未命中。553 冰冻伏特 / 554 极寒冷焰 / 728 流星光束 属同类措辞，同样漏判。

**精确判据取证**（`probe_charge_precise.js`）：OLD 命中 16 招，新判据额外命中 **5 招且零误伤**，合计 21 招：

- 僵直/隔回合：63 破坏光线、416 终极冲击、439 岩石炮、307 爆炸烈焰、308 加农水炮、338 疯狂植物、723 无极光束、722 流星突击、963 幽灵夜曲
- 消失次回合命中：19 飞翔、143 神鸟猛击、467 暗影潜袭、566 潜灵奇袭、972 准备好了、988 剧毒俯冲、901 电光束
- 两回合蓄力（新增）：**76 日光束、632 日光刃、553 冰冻伏特、554 极寒冷焰、728 流星光束**

**明确排除（误伤防线）**：

- 248 预知未来 / 353 破灭之愿 —— `2 turns later`，是延迟命中不是蓄力
- 117 忍耐 —— `to retaliate`，机制不同

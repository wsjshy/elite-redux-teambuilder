## 二、根因

三处文案同源于 **s 级潜力口径**（成卡阶段拿不到最终 build）：

| 落点 | 函数 | 判据 |
|---|---|---|
| `条件威力(已满足)` | `costOf` 天气块（`index.html` L1921–1925） | `ok = wxConditionMet(s)` |
| `雨天必中×1.05 / 雪天必中×1.05` | `weatherAdjOf`（L1944） | `WX_NEVERMISS={'雨':[87,542],'雪':[59]}` |
| `体系加成 X ×N（雨/雪/晴/沙）` | `sysMvAdj`（L15465 / L15480） | `ownWxList` 过滤 |

`wxConditionMet(s)` = `ownWxList(s,learnOf(s)).length>0`，而 `ownWxList` 分两档：

1. **天性** `s.inns` 里的设置手特性（`abiSetOf` 经 `SYS_SET` 映射，固定生效）；
2. 「**能学**设置招 240/241/201/258/604/641/580/581/950 且体系 ∈ `coreSys(s)`」的**手动潜力**，最后按 `coreSys` 过滤。

即：卡面只"能学"求雨、特性池只"可选"降雨，就被当成「已满足」，免掉 ×0.7 代价 —— 估价合理，**展示越界**。

### 截图工程坑（务必记住）

答案卡内容在**内部滚动容器**里 —— 承载页面的是 `MAIN`（`overflow-y:auto`，`scrollHeight 16391 / clientHeight 849`），**不是 window**。因此：

- `window.scrollTo / scrollBy / scrollIntoView` 全部无效（`rect.top` 恒为 1455）；
- `Page.captureScreenshot` 的 `clip` 用文档坐标会越界（`absY 1571 > docH 1016`）并**挂起**；
- 正确做法（`cdp_shot4436k.js` 骨架）：
  1. `Input.dispatchMouseEvent` 真实点击 `SUMMARY` 展开「引擎视角」；
  2. 在 `#coreOut .mvuse` 中找文本最短的命中块；
  3. 迭代收敛 4 轮：`main.scrollTop += (el.top - main.top) - 110`，每轮 sleep 650ms，`delta <= 6` 即停；
  4. 普通 `Page.captureScreenshot`（无 clip）。

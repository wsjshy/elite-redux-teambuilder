# v4.421 测试报告 · 核心列表加载更多（2026-11-21）

## 1. 背景

用户反馈：核心配队默认只显示前 60 只，324 只命中也只能靠缩小筛选，无法继续往下看，要求支持进一步显示。

## 2. 现状与方案

- 原 `draw()` 硬编码 `slice(0,60)`，coreMore 仅显示计数与「可缩小筛选」。
- 主图鉴 `renderSp` 已有 `spShown/spStep` + 滚动触底追加的成熟模式，本次复用同一思路，不新造轮子。

## 3. 改动

- 核心 IIFE 新增 `coreShown`、`coreStep=60`，抽出 `coreArr()` 负责过滤、数字置顶、排序。
- `draw(reset)`：reset 清空并从 0 开始；否则按 `slice(coreShown, coreShown+coreStep)` 追加。
- coreMore 有剩余时显示「加载更多（还有 N 只）」按钮；同时新增 main/window 滚动触底（距底 400px）自动追加。
- 搜索/筛选/排序/开关事件统一走 reset；外部 `drawCoreList` 包成 `draw(true)` 保持全量重绘契约。
- 已全部显示时滚动重复触发直接 return，不做多余 DOM 改动。

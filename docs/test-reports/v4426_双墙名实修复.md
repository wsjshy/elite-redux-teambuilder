# v4.426 测试报告：双墙辅助流名实修复

- 版本：v4.426（2026-11-23）
- 性质：根因级判定修复，覆盖整个「双墙辅助流」品类，非个案打补丁。
- 产物：`index.html` 2,126,977 → **2,134,359 B**（净增 7,382，分 patch4426 a–j 共 10 个脚本）。

## 一、立项与用户三问

用户带超级胡地 #1507 截图（淘气/剩饭/单反射壁/耐久 EV）提出三问：

1. 胡地这种玻璃大炮耐久（55/50/65/175/105/150，bulk 225）做辅助是否大材小用；
2. 名为「双墙辅助流」为何只带一面墙；
3. 若高速手确可开双墙，队友能否继承双墙的战术价值（强化推队）。

要求根因级修复并覆盖整个双墙品类，是继 v4.425「进攻手手动场地招门控」之后同一主题（名实不符/职责建模缺陷）的延续。

## 二、根因（取证闭合）

双墙卡由 `comboBuildsOf` 用「通用坦克默认模板」批量生成，无物种适配、不保证双墙名实相符、且绕过 finalize。

1. **生成无准入、模板张冠李戴**：墙块条件仅「学到任一面墙 + 有本系招」，任何物种都生成；默认补全块对 isTank（名含钉子轮转|双墙）统一塞剩饭/淘气（+物防−特攻，直接削胡地 175 特攻）/耐久 EV。同函数钉子流早有 `&&!isGlassCannon(s)` 门，墙流却没有。
2. **组合卡绕过 finalize、只含一面墙**：组合卡只过 `sanitizeBuild`、不进 `finalizeBuildInPlace`，finalize 墙块（needW=autoW?2:1）与光之黏土成套均不作用；模板只放一个墙 id，sanitize 再把重复占位替换成攻击/回复招，最终剩饭+单墙只持续 5 回合。
3. **队友挑选无强化推队手职责**：needList 只有 wallp/walls/cover/haz/rec，无 sweeper 类；MATE_ROLE_PRIO 受队行无「强化」项，强化手不会被选中。

## 三、ER 机制（源码 `D:\game\scratch\eliteredux-source`）

`include/battle_util.h`：SCREEN_DURATION=5、SCREEN_DURATION_EXTENDED=8（光之黏土）、SCREEN_DURATION_SHORT=3（极北之风自动极光幕）。光之黏土 HOLD_EFFECT_LIGHT_CAY（battle_script_commands.c、battle_skills.cc）对光墙/反射壁/极光幕均延长至 8 回合。

## 四、补丁（patch4426 a–j）

1. 重写 comboBuildsOf 墙块，立真双墙准入（同时会 113+115，或会 657 且自带雪系特性 id 集 [117,666,929,291,348,870,493]）；分玻璃大炮高速开墙（胆小/满速 EV）与耐久种耐久开墙（防御性格/耐久 EV）两配置，统一光之黏土，新增 `_fastScreen` 哨兵。
2. sanitizeBuild 对哨兵放行保住速攻 EV/性格；修复组合卡补全块 EV 空值误判（EV 是对象无 `.length`，旧 `!b.ev.length` 对带 alloc 对象恒真，改 `!b.ev.alloc&&!b.ev.length`）——这是胡地保住速攻 EV [4,0,0,252,0,252] 的关键。
3. 极光幕收紧：v4.395 会清非雪系手的手动冰雹 258，故仅雪系特性物种走 657，无雪特性的 41 物种不再生成极光幕卡。
4. v4.392/v4.394 旧改名块的单墙卡不再冠名双墙，改「稳健联防」（真双墙=113+115 或 657）。
5. 新增 NEED_KINDS 的 `sweep`（gate 查 `_ER_BOOST_ROLE`+atkBest 力度），needList 核心会墙时 add('sweep',5)，答案卡第 4 槽强制强化角色；强制角色改全池硬扫描 `_scan4426`（只接受带该空闲角色的候选，无候选才回退常规贪心）。
6. `_forceSweep` 触发条件与真墙手口径对齐（盖欧卡仅学 657 无雪源不触发）；共用弱点替换的角色承继校验从「仅天气手」泛化到任意角色，杜绝挂名。

## 五、量化结果

- 全库墙卡 **352 张**：普通双墙 318、极光幕 34、单面墙 0、全部光之黏土；GC 高速开墙 74、非 GC 耐久开墙 278。
- 快照对账 4197→4138 卡（净减 59）：411 旧墙卡移除、352 新卡加入、331 物种签名变化。
- **80 个物种失去墙卡**（如可达鸭、闪电鸟、雷公、坚盾剑怪），probe 核实改后均仍有 1–5 张其他流派卡、**零卡物种为 0**；约 21 个物种新获得墙卡。
- 会 657 且有雪特性物种 34 个（如拉普拉斯降雪、几何雪花北风、铁包袱降雪）；会 657 但无雪特性 41 个（不再生成极光幕卡）。

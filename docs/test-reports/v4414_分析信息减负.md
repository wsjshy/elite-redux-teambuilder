# v4.414 测试报告 · 分析页信息减负（2026-11-21）

## 1. 立项依据（用户真实反馈）

用户原话：**「继续推进，目前感觉好多内容尤其分析还是太繁杂了，导致信息获取难度太高了」**。

痛点集中在「队伍分析」Tab：检查分类多、术语密、真问题被大量「没问题」的确认型条目稀释。本版目标是做减法与信息分层，让玩家第一眼只看到真正需要处理的问题。

## 2. 现状量化（改前基线，CDP 实测）

测试队：六人队 [26 雷丘, 65 胡地, 96 催眠貘, 80 呆壳兽, 37 六尾, 208 大钢蛇]，视口宽 1300px。

| 指标 | 改前 |
|---|---|
| 整个分析 Tab 高度 | 1741px |
| 文字量 | 1706 字 |
| 卡片容器 | 36 个 |
| 体检卡高度 | 596px |
| 体检卡可读条目 | 25 个 |

体检卡 25 条构成：

- 3 个速览行（胜负手 / 钉子 / 入场税，其中入场税一行平铺 12 个百分比）。
- 3 条红色硬伤。
- 11 条橙色提示（默认只露 2 条）。
- 8 条灰色参考（打穿速度、最坏情况、换哪招等小众数学）。

另有 17 个检查分类名平铺 + 约 150 字方法论段落。

勘察识别出的核心问题：

1. **概念面过宽**：17 个分类 + 大量术语，学习成本高。
2. **正面确认稀释真问题**：「没问题」型参考条目与真硬伤混排。
3. **同源重复**：弱点在体检硬伤 / 联防 / 诊断三处重复；钉子在速览行与提示重复。
4. **近义条目冗余**：先制弱点 3 只各出一条近乎相同的文案；体系标签与细化体系语义重叠。

# v4.402 全面汉化测试报告

- 引擎版本：v4.402
- 测试日期：2026-11-18
- 主题：玩家可见英文残留全面清零（招式描述 / 物种名 / 招式名 / 道具描述 / 特性名与描述）
- 触发：用户截图反馈「招式详情弹窗里描述是英文，需要优化，工具里面尽量都汉化」

## 一、问题与根因

### 1.1 弹窗 bug（核心根因）

用户截图为超级喷火龙Y（#1503）的「招式·羽栖」弹窗，描述行显示英文 `The user lands and rests its body. It restores the user's HP by up to half of its max HP.`

排查发现 `mvModalById` 函数写死读取英文条目：

```js
// 改前
esc(m[10]||m[9]||'（无描述）')
```

它**从未读取 `ERDATA.mvDescZh`**。反证：#355 羽栖在 mvDescZh 里其实早有中文「落地休息，回复最大HP的一半。」，却仍显示英文——这是纯展示层漏读，不是数据缺失。

修复（复用现成函数 `mvDescOf`，逻辑=先读 mvDescZh 否则回退 m[9]/m[10]）：

```js
// 改后
esc(mvDescOf(m)||'（无描述）')
```

OLD/NEW 等长，index.html 字节数不变，CRLF/LF 不变。

### 1.2 数据层英文残留

弹窗 bug 之外，全库扫描发现卡片范围内仍有四类英文残留，逐一量化后处理。

### 2.2 35 个物种中文名

判据：剥离形态后缀（超级前缀 / 末尾 R·X·Y·Z·B·Ex / -形态 / (P)(N)）后，核心名是否纯英文。含拉丁字母但属「中文 + 形态后缀」的（大钢蛇R、超级喷火龙Y、未知图腾-B）玩家可懂，不动。

### 2.3 道具只译「卡片可见」

全库约 700 个英文描述道具，大量是精灵球/非对战道具；按卡片实际用到的 48 种道具判据，只译其中 39 个英文描述 + 补 1 个空描述（大葱）。

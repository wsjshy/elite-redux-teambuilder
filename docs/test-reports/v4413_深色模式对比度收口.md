# v4.413 测试报告 · 深色模式对比度系统收口（2026-11-21）

## 1. 立项依据（用户真实反馈）

用户反馈「深色模式做的不好，很多字看不清」，并附两张截图：

1. `spDrawer` 宝可梦详情弹窗中，特性 / 天性 chip 文字不可见（浅色字压 `#f8f9fb` 近白底），白色「进化链 / 相关形态」整盒文字不可见。
2. 图鉴页属性筛选条 `#spTypeChips` 深灰 chip 上深色属性名几乎不可见。

用户底线原话：**「这种白底白字，黑底黑字的至少不应该出现」**。

## 2. 根因勘察

深色模式原实现仅一个 `#themeOverride` style 块，只覆盖 CSS 变量；全库 CSS 有 167 个唯一 hex、265 处硬编码，style 块外 JS 内联样式另有 117 个唯一 hex、300 处。

- 大量硬编码浅色表面（`.abi` / `.abid` / `.mvdesc` 的 `#f8f9fb`、`.acc` / `.poolscroll` 的 `#fcfdff`、`.mtcfg` 的 `#f4f6fa`、`.mate.main` 的 `#f6fef8`、`.slot` 的 `#fafbfc`、`.tr` / `.evsegs` / `.badge-neu` 的 `#eef0f4`、`.spbox` / `.spmiss` 的 `#eceff3` 等）深色下不换，文字却继承浅色 `--text`（#e8eaed），浅字压浅底——截图不可见文字的根因。
- 部分元素无显式 color（nav button、`.btn`、`.chips button`、`.modal .close`），浏览器默认黑字压深色卡，审计实测对比度 1.48–2.04。
- `--acc`（回退 #1976d2）与 `--fg`（回退 #111）从未定义，回退色恒生效；`--ok` / `--warn` / `--danger` 已在 `:root` 定义但深色块未覆盖。

## 3. 修复方案（五批字节级补丁，锚点 count==1，插入块 CRLF）

### patch4413a · 表面变量化
19 个浅色硬底 hex 全局替换为新变量（`--soft1`…`--soft6`、`--track`、`--spbox`、`--hover-row` / `--hover-sum` / `--hover-card` / `--hover-chip`、`--soft-warn` / `--soft-bad` / `--soft-info` / `--soft-empty` / `--soft-hit` / `--soft-ok2` / `--gray2` 等），浅色值逐位保留（零浅色回归），在首个 `:root` 与深色块各插一组声明（深色值如 `--soft1:#2f3540`、`--soft4:#1f3327` 绿调、`--track:#353c47`）。

### patch4413b · 前景变量化
49 个前景 / 零散浅底 hex 替换为变量，含 `--ok`（76 处 #2e7d32）、`--fg-warn`（21 处 #b26a00）、`--acc`（5 处 #1976d2，现定义浅 #1976d2 / 深 #7db4ff）、`--fg-bad` / `--fg-purple` / `--fg-teal` / `--fg-gray` 系列、`--fg-red` 系列 4 个、`--fg-orange` 系列、`--fg-blue-dk` 系列等，以及 `--soft-bad2` / `--soft-warn2` / `--soft-purple` / `--soft-blue` / `--soft-green` 等配套底色。对 5 处既有变量声明行用 NUL 占位符保护后再替换。

### patch4413c · 深色覆盖块 + 漏网处理
`#fde` → 新变量 `--soft-bad3`；`var(--fg,#111)` → `var(--fg)` 并定义 `--fg`（浅 #111 / 深 #e8eaed）。在 themeOverride 内追加 30 条 `html[data-theme="dark"]` 规则：按钮 / 关闭默认文字（`:not(.active/.primary/.on)` 排除显式白色态）统一 `var(--text)`；`.bar input` / `textarea` 白底改 `var(--soft1)`；三个 `.split-*`、九个 `.mtag.*`、`.own.yes`、`.ev2` / `.ev0`、`.qa-chip`、五个 `.spd-p*` 分位染色、`details.mechdet` / `.mechsec h3`；答案卡 / 概要卡子系统（`.anscard` / `.spans` 深底 #232c3e、`.anshd` / `.ansrow` / `.ansmv` / `.ansmate`、`.ansm` / `.ansp` / `.ansclk` 白 chip 改深底 #2e3848 及各 hover 态）。

### patch4413d · 第二轮审计收口
- 漏网浅底 `#f8fbff` → 新变量 `--soft6`（浅 #f8fbff / 深 #263042）；
- `.lcard` 实为 `<button>`，UA 默认黑字 → 深色 `var(--text)`；
- 所有 `.close`（含 lmod / mqm / l1Modal 内）→ `var(--text)`；
- 无 class 锚点（默认 UA 链接色 #0000ee，如「跳到可学招式表 ↓」）→ `#8ab8ff`；
- 绿色徽章组（`.badge-res` / `.badge-pick` / `.badge-pickable` / `.badge-super` / `.okmini`，原深绿字 #1b5e20 压深绿底 1.72）→ 字色 `#9ad8a4`，`.badge-pick` 浅底改 rgba 绿 + 边框；
- `.tip` 深色字色改 `var(--text)`；
- `--hi` / `--hi2` 深色值（原 #1565c0 / #6a1b9a 深字）→ `#82b4f0` / `#b08fd8`。

### patch4413e · 链接变量与存档盒收口
- 存档解析结果盒等 4 处 `#eef6ff` → `var(--soft-blue)`；
- 全库 90 处 `color:var(--accent)`（文字型 accent，含 JS 内联样式）→ 新变量 `color:var(--link)`，定义浅 #2563eb / 深 #8ab8ff；按钮背景仍走 `--accent`，白字对比度不受影响。

## 4. 自验：四轮运行时对比度审计

审计探针强制深色（html 加 `data-theme` 且初始化改 `erApplyTheme('dark')`，避免页面加载时被 localStorage 默认 light 覆盖），自动遍历 12 个视图（core-landing、core-answer[selectCore(1503)]、poke-list、sp-1503、sp-27、team、analyze、speed、move、abi、tpl、type），页面内对每个有自有文字元素做 WCAG 对比度计算（含 rgba 背景沿父链 alpha 合成）。

| 轮次 | unique 违规分组 | 说明 |
|---|---|---|
| 第一轮 | 大量（阈值 4.5） | 基线，浅字浅底 / 黑字深底普遍 |
| 第二轮（patch a-c 后） | 49 | 硬伤基本消除，剩类型标签与 accent 文字 |
| 第三轮（patch d 后） | 35 | 绿徽章 / 关闭 / 链接 / lcard 已收口 |
| 第四轮（patch e 后） | **27** | 剩余全部为品牌色保留项（见下） |

第四轮剩余 27 组分类：

1. 类型标签 `.t.t-*`（白字品牌色，浅色模式同口径，非不可见，r 1.6–3.1）；
2. 白字彩色按钮 / 徽章 / 分位 chip（品牌色设计，浅色模式同口径，r 1.97–3.84）；
3. 临界灰字两组（天气手 r4.47、橙色警示 r4.28、命中红 r3.70），肉眼清晰可读。

**结论：白底白字、黑底黑字类不可见文字（r < 1.5 的真实硬伤）归零。**

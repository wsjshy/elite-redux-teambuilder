## 八、事故与教训

1. **区间重叠 → 文件被复制一份**（两次重犯）：v4.395b 段**嵌套在 v4.395 块内部**，按三个起点各取区间时 `sorted(spans)` 后者嵌套于前者，`prev` 指针导致反向切片为空 → v4.395b 段被复制、size 暴涨到 2,078,525。**结论：取补丁区间必须先确认互不嵌套；这里只能取一个从 `/* v4.394` 到 `catch(eV4395b)` 的连续区间。** 已改写 `fix_catch_v4395.py` 为单一连续区间，回滚源 `%TEMP%\index_before_v4395b.html`。
2. **展示名 ≠ 数据名**：第一版用特性**展示名**正则判天气手 → 误命中 57 / 47 张假阳性。因为「干旱」= 日照(70)、「白茫茫」= 冰天雪地(269)（`abiDispName` 全局映射）。**判来源只能用特性 id 白名单。**
3. **正则漏字静默失效**：`速攻?强化清场` 把「速」写成必需字符 → 全部漏匹配、改名数为 0 但不报错。必须断言「未替换」计数。
4. **空 catch 阈值卡线**：`tools/smoke.js` 判 `if (n > 390) throw`；HEAD(v4.393) 本身已是 390。回滚重做后工作区 391，补修 `}catch(eS){}` → `{eS.name}` 才回到 390。**新增块一律用 `catch(eX){eX.name}`，不用空 catch。**

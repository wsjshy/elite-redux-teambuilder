## §0 全局设计原则

### 0.1 六位职责（冻结次序）

| # | 位置 | 职责 | 必填要点 |
|---|---|---|---|
| 1 | 体系核心 | 设置手/轴手：谁开轴、开轴条件、回合数 | 角色 / 要求 / 依据 |
| 2 | 打手位 | 轴收益变现者：速度线、力度、受益特性/招式 | 速度线 / 力度要求 / 受益 / 依据 |
| 3 | 补盲位 | 覆盖该轴天敌（引用克制表与弱点体系） | 目标天敌 / 属性招式 / 依据 |
| 4 | 联防位 | 承接该轴弱点（免疫/抗性特性引用） | 承接弱点 / 特性属性 / 依据 |
| 5 | 撒钉清钉轮转位 | 铺钉/除钉与轮转节奏 | 铺钉 / 清钉 / 轮转 / 依据 |
| 6 | 功能位 | 控速/回复/干扰 | 控速 / 回复干扰 / 依据 |

### 0.2 三条硬约束

1. **「6 位 ≠ 6 只」**：ER 每只可战前切 3 选 1 特性池（`abis`）+ 3 天性（`inns`），一只可担多职（组队理论 §13.6）。模板 6 位可用 ≤6 只填满，各轴 note 已给「兼位」实例。
2. **依据禁止拍脑袋**：只允许四类来源 —— ① 轴库本轴既有条目；② 组队/对战理论文档（`_03`/`_02`）；③ ER 机制知识库与口径表（`GLOSSARY.` / `ABI_TAGS` / `FUNC_MV` / `TEMPLATES[` / `_机制默认口径表 §x`）；④ 外部机制事实的 Bulbapedia/Smogon URL。引用风格沿用既有轴库（如「TEMPLATES[雨天速攻]」「ABI_TAGS[33]」）。
3. **内容溯源**：所有特性/招式引用落到 ER 实际条目；物种取名取自 ER 图鉴数据（`docs/研究资料/_erd_slim.json`，与 v4.2 轴系探测计数一致，如 降雨 abis 21 / inns 5）。

### 0.5 命名陷阱（引用时须区分）

- **道具岩石**：`潮湿岩石298`（雨）/ `炽热岩石297`（晴）/ `光滑岩石296`（沙）/ `冰冷岩石295`（雪）。⚠️ abilities[70] 文案写「炎热岩石」，实为同物，落库以 `id 297` 为准。
- **巨翼**：`巨翼688` = 「巨大翅膀371 + 飘浮26」复合特性；而别名表「巨翼 → 371」是纯 `巨大翅膀`（无飘浮）。引用时须区分 688 与 371。
- **毒系特性**：`毒素吸收344`（毒招回复 1/4）/ `毒疗90`（中毒回 1/8）/ `中毒激升137`（中毒攻×1.5，且在剧毒地形上自我中毒）—— 三者不同。
- **场地制造机326**：ER 源码 `gameData.items` 含 id 326；`_erd_slim.json` 的 929 条道具子集未收录，故不可据 slim 表判定其不存在。

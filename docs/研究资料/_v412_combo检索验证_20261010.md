### 1.1 `multiscale_disguise_sturdy`（+3，保命道具×特性触发次序辨析）

**② 多重鳞片 × 气势披带（item 287 / cond ability 136）**
- effect：多鳞片满血减半后若不足以致死，披带不会被消耗；两者覆盖面高度重叠，且对连续攻击招都只对首段生效。

**③ 幻影防守 × 气势披带（item 287 / cond ability 231）**
- effect：幻影防守与多鳞片同为满血减半，但幻影防守**不可被任何招式/特性无视**，因此更能把披带留到真正需要时。

## 3. 放弃登记（检索/证据不足或机制为反效果，一律不写）

**A. ER 同池物种数 = 0（硬证据，必须放弃）**
- **魔法防守 + 毒疗**：同池物种 0 → 放弃（原计划为「免钉 + 每回合回血站场」的核心设想）。
- **再生力 + 毒疗**：同池物种 0 → 放弃。
- **多重鳞片 + 画皮**：同池 0 → 放弃。
- **结实 + 多重鳞片**：同池 0 → 放弃。
- **火焰之躯 + 静电**：同池 0 → 放弃（故「双接触异常」改用毒刺 + 剧毒碎屑实现，见 1.5②）。

**B. 机制为反效果，不登记为 combo（仅作辨析留档）**
- **威吓 × 欺诈**：欺诈「套用**目标**的物攻等级变化」，威吓把对方物攻 −1 会**直接压低欺诈伤害**，二者在输出上互相抵消。来源：https://bulbapedia.bulbagarden.net/wiki/Foul_Play_(move)（原文「The target's Attack stat stage-modifiers are applied (rather than the user's)」）+ https://bulbapedia.bulbagarden.net/wiki/Intimidate_(Ability)。
  - 处理：不写入草稿 JSON（库内有「反效果组合被删除」的先例），改以 `body_press` 条的 note 记录辨析，并在此留档。
- **结实 / 多重鳞片 / 幻影防守 与 气势披带**：严格说是「触发区间重叠、收益被覆盖」，因任务方向①明确要求辨析且其触发次序本身有战术价值（何时披带才真的会被消耗），故按正向条目登记并写明重叠风险；**未**按「纯反效果」处理。

**C. 来源/机制链不足，放弃**
- **「宝石/种子消耗后触发硬撑或绝处逢生」类联动**：宝石/场地种子的消耗只会触发「轻装」等消耗道具体系，与硬撑（需异常状态）、绝处逢生（需低血线）之间**不存在机制因果链**，强行登记即为编造 → 放弃。方向⑤的该分支改由「飞行宝石 + 勇鸟猛攻」（1.13①）与「气势披带 + 绝处逢生」（1.14①，低血线联动）承载。
- **沙鳞果 + 气势披带**：两者同为「低血线一次性保命/提速」，区间重叠；且既有 `reversal` 条目已登记沙鳞果（125）→ 放弃重复登记。
- **轻装（unburden）新增条目**：既有条目已有 (杂技 512, {339,84}) 与 (轻装 84, {339,84})；本轮**未**找到其他能满足「可打开复核的真实来源」的轻装新组合 → 放弃。
- **场地种子（terrain_seeds）新增条目**：既有条目已 3 条（任务方向⑤亦提示满额则换向）→ 本轮不新增。
- **恶作剧之心方向**：既有 3 条（磷火/电磁波/挑衅）已覆盖「先制变化招」主旨；本轮仅新增「先手撒钉」1 条，未再扩列以免与既有重复。
- **`endure_substitute`**：任务方向①③均提到「毒疗+替身压血线」，已按任务指引并入 `poison_heal`（1.4①）而非 `endure_substitute`；该条目本轮无独立新组合。

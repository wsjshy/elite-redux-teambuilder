## 2. 方法

1. **加权使用率**：`weighted_usage = Σ_s ( w_s × chaos[species].usage )`，w = {gen3ou:1.0, gen9nationaldex:0.5}。只读 `Raw`/`usage`，不改 any nn_data 文件。
2. **物种映射**（chaos 名 → ER id）：用 `species_map.json` 的 `tier==1`（= `cls==matched`，norm/showdown 命中 Showdown 图鉴键）建 `showdown键 → er_id` 表；chaos 名按「小写 → ♀/♂→f/m → 仅保留 [a-z0-9]」归一为 showdown 键后查表。唯一同名冲突 `clefablemega`（er 2181/2297）取较小 id；该名未出现在 chaos，不影响产出。
3. **排序取样**：全物种按 `weighted_usage` 降序，取**能映射到 ER 的前 120 个**（rank 截止见 §3）。
4. **百分比口径**：`percent = Σ_s(w_s×count_s) / Σ_s(w_s×Raw count_s) × 100`（Smogon chaos 百分数口径，分母=该物种 Raw count；已验证 gen3ou Tyranitar Σ(Moves)/Raw=4.000）。
5. **id 映射**：招式/道具英文名按同归一键查 `ER-source/gameDataV2.65beta.json` 的 `moves`/`items` 数组取 id；队友名同样经 species_map 映射为 ER id。查不到者**保留名称并注 `note:"未映射"`**。
6. **别名（逐条人工核对，唯一命中）**：16 型 Hidden Power → ER 单一招式 `Hidden Power`(id 237，类型由个体值决定)；ER 内英文拼写差异 `ElectrcMemory(977)/FightngMemory(979)/Poisinium Z(1015)/GldBottleCap(197)` 按语义映射（note 标注）。

## 6. 局限与接入建议（诚实标注）

1. **原版使用率 ≠ ER 使用率**：ER 无对战统计为已知缺口。本库仅作**先验参考**，引擎排序仍须以**机制覆盖 + 协同**为主；建议沿用 `USAGE_PRIOR_W ≤ 0.6`，**只作次排序、改不了量级**。
2. **格式偏移**：gen3ou（同代手感）+ gen9nationaldex（物种覆盖，含 Mega/后世代）混合；个别招式/道具为世代外（如 TR、Z 石、部分记忆），ER 无对应者已登记未映射。
3. **映射边界**：仅取 `species_map tier==1`（=matched）；形态差异（tier=3）与自创（tier=4）未纳入。
4. **百分比分母**：为「该物种出场套数（Raw count）」，非全场；跨源按权重合成。
5. **Mega 单一道具**：13 个 Mega 物种仅 1 件道具（超级石 100%），属真实数据，非缺项。

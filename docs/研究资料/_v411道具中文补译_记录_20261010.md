**c-Mega（221 项）** —— ER 的 Mega 石。命名规则：

> 中文名 = 项目自有物种表 `招式表_宝可梦基础.csv` 中该物种简中名 + 「进化石」+ 官方全角形态后缀（Ｘ/Ｙ/Ｚ/Ｒ/Ｈ/Ｇ/Ｐ/Ｓ/Ａ/Ｅ；后缀字符已包含在物种名中则不重复追加）

- 依据：ER 数据 `species[].evolutions[]` 中 `kd==1`（Mega 石进化）的 `rs` 字段（＝道具的 `NAME` 常量，如 `ITEM_SHEDINJITE`），把常量映射回道具 id 与物种 id；**`in` 字段是另一套 id 空间，不是道具 id，不可用**。

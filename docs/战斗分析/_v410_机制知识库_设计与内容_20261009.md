## 1. 六分类定义、选型理由与逐条归类

分类与引擎判定入口一一对应，六类互斥且正交（口径 / 威力 / 道具 / 顺序 / 环境 / 队伍），避免机制混入通用评分。

| cat | 中文 | 定义与选型理由 |
|---|---|---|
| eval_rewrite | 评估前提改写型 | 机制改变的是评估口径而非威力数字：按对方物攻/自身物防结算、免疫间接伤害、无视对方特性与强化、换场回血、物种级剖面改写。引擎改写评分依据与 why。 |
| power_cond | 威力条件型 | 招式威力随条件放大（无道具/低速/异常/低血/先受击）。引擎按条件重算威力并附加前提标签。 |
| item_link | 道具联动型 | 机制必须由特定道具触发（宝石/场地种子/气势披带/速度果/剧毒珠）。引擎按是否携带及是否消耗性道具判定。 |
| priority | 出招顺序型 | 机制改变出招顺序（变化招先制 +1）。引擎把速度维度替换为与速度无关的效用锚点。 |
| weather_terrain | 天气场地联动型 | 机制依赖天气或场地激活（场地种子）。引擎按场地/天气状态判定，条件不满足则该 combo 不推荐。 |
| teammate | 特性×队友联动型 | 机制效用依赖队友构成（伪装对象、场地制造者）。引擎需队伍级输入（teammateAbility）。 |

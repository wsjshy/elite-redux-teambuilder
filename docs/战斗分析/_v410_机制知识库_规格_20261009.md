## 2. mechLib JSON schema（数据层嵌入 data.js 顶层键 `mechLib`）

文件：`nn_data\mech_lib_v410.json`（不入库，构建期被 build_tool_data.py 读取嵌入；参照 axis_lib.json 先例）。

```json
{
  "mechLib": {
    "meta": {"version": 1, "count": 25, "updated": "2026-10-09", "schema": "v410-frozen"},
    "mechs": [
      {
        "id": "acrobatics",
        "zh": "杂技", "en": "Acrobatics",
        "kind": "move",
        "match": {"moves": [512]},
        "cat": "power_cond",
        "rewrite": "acrobatics_item",
        "params": {"noItemPow": 110, "heldPow": 55},
        "premise": "无道具或消耗性道具（宝石/场地种子）时威力翻倍",
        "impact": {"moves": "杂技", "items": "飞行宝石/场地种子（消耗→威力110）", "nature": "不减益", "ev": "不强制"},
        "combos": [
          {"with": {"kind": "item", "ids": [339]}, "cond": {"consumableItem": true},
           "effect": "飞行宝石本发×1.5后消耗→后续杂技110", "narr": "飞行宝石起手爆发，消耗后杂技全程110",
           "src": "https://bulbapedia.bulbagarden.net/wiki/Acrobat_(move)",
           "note": "宝石×1.5 为官方口径，ER 数据 desc 未载明宝石倍率，登记待实测"}
        ],
        "basis": "无道具时威力×2（110）；ER desc 载 75×1.5，与官方×2 存在口径差，见 §5",
        "src": "https://bulbapedia.bulbagarden.net/wiki/Acrobat_(move)"
      }
    ]
  }
}
```

字段约束：
- `id` 全库唯一；`zh` 用数据中文名；`match` 至少一个非空键（moves/abilities/items/species 之一）。
- `cat` ∈ 六分类：`eval_rewrite`（评估前提改写型）/`power_cond`（威力条件型）/`item_link`（道具联动型）/`priority`（出招顺序型）/`weather_terrain`（天气场地联动型）/`teammate`（特性×队友联动型）。
- `rewrite` ∈ §3 词汇表。`params` 按词汇表定义传参。
- `combos[]` 每条：`with`（{kind: move|ability|item|species, ids:[gameData id]}）、`cond`（§4 DSL）、`effect`（机制描述）、`narr`（**一句话效果叙事**，结构化生成不编造）、`src`（**必填 URL**）、`note`（可选登记项）。
- `basis`+`src`：机制本身依据与 URL，必填。
- **铁律**：每条 combo 的 `src` 必须真实可溯源；检索不到的组合**一律不写**；「杂技+魔术师」禁止出现（用户抓错的反效果组合）；「变身者+气势披带」表述须精确为「保命」而非「提速」。

## 4. combo 条件 DSL（C 引擎判定；条件不满足不推荐）

```json
"cond": {
  "noItem": true,              // 要求无道具位
  "consumableItem": true,      // 要求携带消耗性道具（宝石/种子/气势披带等）
  "item": [339],               // 要求携带指定道具
  "ability": [84],             // 要求自身具指定特性（含天性池）
  "move": [512],               // 要求可学/携带指定招式
  "terrain": "grassy",         // 要求场地激活（electric/psychic/misty/grassy）
  "weather": "rain",           // 要求天气（sun/rain/sand/snow）
  "status": "burn",            // 要求状态（burn/poison/paralysis/sleep）
  "lowHp": true,               // 要求低 HP 战术前提（气势披带/替身/忍耐在配装中）
  "teammateAbility": [42],     // 要求队友具指定特性（按队伍构建判定）
  "opponentType": ["steel"]    // 要求针对属性（威胁库/克制表判定）
}
```

- 引擎对每条 combo 逐键判定：**任一条件不满足 → 该 combo 不推荐**（列表给出但标注「条件不满足」）。
- 个人池投影：若已解析存档（SAV_ROWS 非空），**只显示用户存档拥有对象**（species/ability/move/item 的 id ∈ 存档池）；未解析存档则全量显示并在区块标注「未解析存档，显示全量」。

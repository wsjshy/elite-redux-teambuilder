## 1. 方法与两条方法告诫

三条互相独立的证据链：**A 语法/断言**（自建 Node 框架，DOM stub + `vm` 沙箱，含 `core`/`defect` 两类断言）｜**B 运行时实测**（bu 真实点击 + DOM 断言 + 控制台）｜**C 存档回归**（HTML 自身解析器 + 独立 `er-save-parser` 双证）。

**告诫 1（CSS transition）**：HEADLESS 下 `.drawer` 的 transition 不推进 → 曾误判「右侧抽屉不可见/被遮挡」。禁用 transition 后立即 `left=530`（正常贴右）→ **属测量口径问题，非缺陷**。视觉/几何测量前须禁用 transition。

**告诫 2（精灵图 lazy）**：HEADLESS 下 `loading="lazy"` 的 `<img>` 不参与解码 → 截图呈**灰框**、`naturalWidth=0`（但 `complete=false`、无 `onerror`、`hidden=false`）。置 `loading='eager'` 并重设 `src` 后 **loaded=3 / w=64 / complete=true** → **属渲染时机问题，非缺陷**（磁盘 `assets/sprites/` 共 **1906** 个文件，sp3/sp87/sp1501 均存在）。视觉核验精灵图前须先强制 eager。

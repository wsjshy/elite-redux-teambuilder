### 0.2 判定规则

1. **ER 源码实际实现 = 最高权威**（v2.65 行为以此为准）。
2. 源码与 gameData desc 一致 → **「源码 + 数据双源定稿」**；冲突 → 以源码为准并注明；源码 0 命中 → 单源（desc）并标注；两者皆无 → 待用户游戏内确认。
3. 每个能力按事件分类核对：`onOffensiveMultiplier/onBasePower/onDamage`（伤害）、`onStat`（属性/速度倍率）、`onEndTurn`（回合末回复/掉血）、`onAbsorb/onTryHit`（免疫吸收）、`onStatusImmune`（状态免疫）、`onEntry`（换入）、`onAfterMove`/moveend（偷取道具）。**只认实际常量，不认注释。**
4. 每个行号均以脚本实读核对（见文末核对说明），禁止编造。

### 0.3 共用辅助实现（被多项引用）

- `MUL(val)` / `RESISTANCE(val)` 宏：`v265_src__abilities.cc:133`–`138`
  - `#define MUL(val) MUL_MODIFIER(modifier, val)`
  - `#define RESISTANCE(val) { MUL_MODIFIER(resistance, val); MUL_MODIFIER(modifier, val); }` → **RESISTANCE(1.25) 表示「受到该属性伤害 ×1.25」**（同时乘 resistance 与 modifier）。

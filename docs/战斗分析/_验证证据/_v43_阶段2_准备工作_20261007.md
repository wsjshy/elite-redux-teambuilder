## 2. 接口设计（待 07 更新版钉死参数后实现）

### 2.1 `needList(s, cx)` → 需求清单（动态，无固定 6 项）

```js
/* 需求条目（实例，非模板）：按核心画像即时生成，条数与类型随核心变化 */
{
  id:'REQ-COVER-格斗',      // 需求实例 id（<家族>-<参数>）
  kind:'cover',             // 家族：wxSrc | cover | wall | speed | func | boost | wear | clear
  prio:1,                   // 优先级（越小越先补；07 定阈值）
  label:'补格斗盲点',        // UI 呈现（构建逻辑行）
  why:'核心被格斗 2× 且队内无人抵抗',   // 生成依据（可解释）
  qty:1,                    // 该需求需要几只（动态，可 >1）
  gate:function(t,cx){…},   // 必要条件 = 「能不能干这个活」（正向定位，不是强度门）
  dims:[['D4',2],['D9',3]], // 正向维度与权重（07 定维度组合）
  clears:['REQ-COVER-岩石'],// 满足本需求时同时清零的其它需求（多功能）
  filled:[]                 // 填装结果 [{s,score,why,dims,multi}]
}
```

需求来源（**生成规则由 07 更新版给出，本文只定接口**）：
- 体系无来源 → `REQ-WX-SRC`（天气/场地来源；核心自身是自动设置手则**不生成**该需求）
- `coverHoles(s)` 逐属性 → `REQ-COVER-<属性>`（按盲点严重度排序，数量随核心属性变化）
- 耐久/承伤画像 → `REQ-WALL-P` / `REQ-WALL-S`（**仅当画像判定需要**，不是固定两项）
- 速度画像 → `REQ-TR`（慢速核心需空间）/ `REQ-PRIO`（需先制）/ `REQ-TW`（需顺风）
- 功能缺口 → `REQ-HAZ` / `REQ-CLEAR`（除钉）/ `REQ-SEED` / `REQ-PIVOT` / `REQ-WEAR`（消耗）
- 强化路线 → `REQ-SUB`（替身/掩护）/ `REQ-BP`（接力棒）
- 受队向 → `REQ-SPIN` / `REQ-DRAIN`

**多功能加分**：填充者命中 n 条需求 → `multi = 1 + W_MULTI×(n-1)`（`W_MULTI` 由 07 钉死，先设 0.35 待定）
**终止条件**：`team.length>=6 || 剩余需求 qty 全为 0 || 剩余最高 prio > P_STOP`（可输出 <6 只紧凑队伍）
**输出**：`{reqs, team, audit:{filled,total,reqCoverage,missingReqs,warnings}, overview}`

### 2.2 `deriveBuilds(s)` → 战术流派（2–4 条，命名=打法）

四维画像输入：

| 画像 | 函数（拟） | 输入量 |
|---|---|---|
| 输出画像 | `atkProfile(s)` | 本系最高威力（物/特）×STAB×命中修正；双刀破盾可行性（双侧 base + 双侧本系招 + 破受手段）；强化路径（`boostPhys/boostSpec/boostBoth` + 幅度）；先制/游击（`FUNC_MV.speed/pivot`） |
| 耐久速度画像 | `duratProfile(s)` | `bulkOf`、物/特承伤、速度段位（≤60 / 61–85 / >85）+ 体系受益速度倍率（`SPD_ABI`） |
| 特性池画像 | `abiProfile(s)` | 体系受益（`SYS_MAP`）/免疫（`im`）/减伤（`hf`）/输出倍率（`out`）/属性转换（`conv`） |
| 功能招画像 | `funcProfile(s)` | 钉子/除钉/回复/控速/天气/场地/强化/破受（挑拨/剧毒/催眠） |

流派对象：

```js
{ id:'B1',
  name:'晴速攻强化清场',                 // 命名 = <体系前缀><节奏><打法>（07 定词表）
  side:'特殊', roleTag:'输出',           // 供 buildMoves/pickAbiFor/pickAttacks 消费
  basis:[ {k:'output', txt:'本系飞叶风暴 130 ×1.6 = 208'},
          {k:'abi',    txt:'叶绿素（晴）提速（体系受益）'},
          {k:'boost',  txt:'生长：晴下攻/特攻双倍'}, … ],   // ≥2 条依据（UI 展示）
  plan:{ boost:[74], rec:[235], func:[…], order:[…] },     // 招位优先级
  prio:1 }
```

规则要点：
- **命名不=物特二分**：`双刀`只作为「破盾路线」之一，且需 `双侧可行 + 破受手段` 才生成
- 去重（同侧同打法合并）+ 上限 4 条；`prio` 排序决定推荐流派首卡
- 流派名示例词表（07 定稿）：`晴速攻强化清场` / `空间慢速重炮` / `钉子受队消耗` / `游击轮转补盲` / `强化接力轴` / `双刀破盾` / `天气双核清场` / `场地控制站场` / `吸血站场消耗`

## 3. 努力值分配（v4.11 唯一新增数据输出）

### 3.1 结构

在 `deriveBuilds` 循环内产出（L4771）：

```js
b.ev = buildEvs(s, b.side, b.roleTag, b.name);
// → { template:'速攻'|'耐久'|'空间低速', alloc:[hp,atk,def,spa,spd,spe], summary:'252HP / 252攻 / 4防' }
```

- `alloc`：长度恒为 6 的整数数组，槽序 **HP / 攻 / 防 / 特攻 / 特防 / 速**（与规格一致）
- `summary`：非空文本摘要（拼装自非零槽）
- `template`：模板名（非空）

### 3.2 模板选取逻辑（`buildEvs`，入参 `side`/`roleTag`/`buildName`，内部取 `coreRole(s).role` 辅助判定）

| 判定顺序 | 条件 | 模板 | alloc |
|---|---|---|---|
| 1 | `base.spe ≤ 50` 且（`prof.role` ∈ {慢速炮台, 空间打手} 或 `roleTag`/`buildName` 含「空间」） | **空间低速** | 252HP + 252主输出 + 4防；**速 0** |
| 2 | `roleTag` ∈ {肉盾, 受队} 或 `prof.role === '肉盾'` | **耐久** | 252HP + 252主防 + 4另一防；**物防≥特防 → 物盾（物防 252），否则 → 特盾（特防 252）**（按定位动态取） |
| 3 | 其余 | **速攻** | 252速 + 252主输出 + 4HP |

**主输出槽**：`side === '特殊'` → 特攻(3)；`物理` / `双刀` → 物攻(1)。

**UI 附注**：空间低速模板的说明文案含「**速度归零仅为建议，服务铃等机制可提速**，请按自己队伍的调速需求再定。」（`evWhyTxt`，探针 D7d 断言）。

### 3.3 UI 呈现（L2 ⑥，`evBarHtml`）

一行「数组」+「摘要」+「模板名」：`数组（HP/攻/防/特攻/特防/速）**0/252/4/0/0/252**　·　252HP / 252攻 / 4防　·　模板：**空间低速**`；下方 **252/252/4 横向条形图**（`.evsegs` 内 6 段 `.evseg`，宽度按占总量比、`title` 给出「HP 252」等；**主投饱和色 `.ev1`=`--accent` / 副投次饱和 `.ev2`=#7ea8f0 / 余量浅色 `.ev0`=#dbe2ec**）；点条形图（`.evtap` button，`aria-expanded`）**就地展开**模板说明一句话（`.evwhy`，初始 `hidden`）。
